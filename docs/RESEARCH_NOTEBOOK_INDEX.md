# Research Notebook Index

This section holds the deeper technical and investigative notes behind the project.

## Notebook sections

- `01-device-baseline.md` — capture a first clean baseline for a device or machine
- `02-suspicious-telemetry-review.md` — review unusual activity and classify it
- `03-home-lab-risk-scenario.md` — simulate a realistic internal risk scenario
- `04-hardening-plan-template.md` — propose a remediation path
- `05-comparison-review-template.md` — compare before and after changes
- `06-correlation-brief.md` — connect multiple clues into one narrative
- `07-observability-drilldown.md` — dig into the real causes behind a suspicious pattern

## Why this matters

The notebook turns raw observations into structured evidence. That makes the project feel more like a real research pipeline than a loose collection of scripts and notes.

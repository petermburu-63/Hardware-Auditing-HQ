# Project Index

This document acts as the central map for the repository. The goal is to keep navigation simple, professional, and easy to extend as the project grows.

## Core domains

### 1. Hardware and device review
This repo started as a hardware audit and system review archive. It is designed to capture device posture, operating state, telemetry exposure, and practical observations.

### 2. Cybersecurity lab tooling
The project includes a structured set of lab-safe scripts for:

- service discovery
- port review
- telemetry and log interpretation
- file integrity monitoring
- risk scoring and reporting

### 3. Research and notebook work
The repository includes technical notes and templates for:

- baseline comparison
- suspicious activity review
- hardening planning
- operational risk narrative

## Architecture overview

The repo is deliberately split into three operational layers:

1. discovery and reconnaissance
2. defensive monitoring and integrity review
3. analytics and risk interpretation

This separation makes the workspace easier to reason about and easier to extend without making it one giant mixed bag of scripts.

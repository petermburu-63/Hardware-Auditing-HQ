# Cybersecurity Projects

This folder groups the cybersecurity project collection into clear categories for easier navigation and use.

## Categories

- Offense: tools used for recon, scanning, vulnerability mapping, and attack simulation.
- Defense: monitoring, detection, deception, and protection-focused tooling.
- Docs: explainers and project notes for each exercise.

## Structure

- `offense/` — offensive/security-recon project scripts
- `defense/` — defensive security scripts
- `docs/` — markdown project explanations
- `requirements.txt` — Python dependencies for the project set

## Suggested setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
